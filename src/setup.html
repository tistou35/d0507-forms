ตัวอักษรและตัวเลขล้วน อย่างน้อย 6 ตัว · บอกเจ้าตัวแล้วให้เปลี่ยนเอง

แสดงในตัวเลือกผู้รับ — ห้ามใส่อีเมลหรือเบอร์โทร

ไม่เลือกเลย = ไม่ปรากฏในตัวเลือกผู้รับและไม่ได้รับงานอนุมัติ

นำเข้าหลายคน — วางรายชื่อ ตรวจก่อน แล้วสร้างบัญชีทีเดียว

หนึ่งบรรทัดต่อหนึ่งคน คั่นด้วย Tab หรือจุลภาค: ชื่อ–นามสกุล · อีเมล · ปีเกิด (ค.ศ.) · ตำแหน่งใน AeroFBO · รหัสผ่านตั้งต้น = อักษรแรกของชื่อ (ตัวใหญ่) + อักษรแรกของนามสกุล (ตัวเล็ก) + ปีเกิด ค.ศ. · คนที่มีในระบบอยู่แล้วจะข้าม ไม่แตะบทบาทเดิม

ระบบส่งข้อความทาง LINE Official Account ของโรงเรียน ทีละคน ไม่ใช่กลุ่ม — แต่ละคนได้เฉพาะเรื่องของตัวเอง (งานที่ส่งถึง ผลของใบที่ส่ง งานค้าง ฯลฯ ดูรายการด้านล่าง) · ตัวตั้งเวลาของตัวส่งออกตรวจเรื่องใหม่ทุก 1 นาที และส่งรอบเช้าตอน 08:00 ไม่ขึ้นกับว่าใบถูกส่งจากเครื่องไหน · ยังไม่ใส่ token หรือยังไม่เปิดส่งจริง = ไม่มีอะไรออกจากระบบ แต่ทุกข้อความที่ "จะส่ง" ลงบันทึกด้านล่างพร้อมเหตุผล

—กำลังตรวจ…
Channel access token เก็บที่ตัวส่งออกเท่านั้น ไม่มีทางอ่านกลับ

คัดลอกจาก LINE Developers › Messaging API › Channel access token (long-lived) แล้ววางที่นี่ ระบบตรวจกับ LINE ก่อนบันทึก ถ้า LINE ไม่รับจะไม่บันทึก · ใช้ channel เดียวกับ D0507 Dispatch LINE user ID ที่ Dispatch เก็บไว้จึงใช้ได้เลย (user ID ของ LINE ผูกกับ provider)

ปิดไว้ = บันทึกอย่างเดียว (ทดลอง) · เปิดเมื่อใส่ token และตรวจรายชื่อแล้ว
